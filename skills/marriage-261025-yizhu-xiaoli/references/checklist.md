# 检查表

## 事实与材料自查

- [ ] 所选形式与法律规定的要件是否逐项对应
- [ ] 自书遗嘱是否全文亲笔书写、本人签名并写全年月日
- [ ] 打印遗嘱是否每一页都有遗嘱人和见证人签名及日期
- [ ] 录音录像是否记录了姓名或肖像以及年月日
- [ ] 见证人是否已排除无见证能力人、继承人、受遗赠人及有利害关系的人
- [ ] 立遗嘱时的民事行为能力是否有材料可以证明
- [ ] 是否已为缺乏劳动能力又没有生活来源的继承人留出必要遗产
- [ ] 多份遗嘱是否已按时间排序并明确各份的效力状态

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
