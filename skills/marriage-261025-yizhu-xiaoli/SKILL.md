# 遗嘱形式与效力

> 六种遗嘱形式、形式要件与多份遗嘱冲突

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「遗嘱有哪些形式？」「自己写的遗嘱有效吗？」

**什么时候会用到它**：

- 遗嘱有哪些形式
- 自己写的遗嘱有效吗
- 有多份遗嘱以哪份为准

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
遗嘱有哪些形式？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于六种遗嘱形式的要件核对，也适用于自书遗嘱的效力判断、见证人资格的审查、必留份的处理、多份遗嘱相互抵触时的效力认定，以及遗嘱无效情形与附义务遗嘱的履行争议。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 选择遗嘱形式 | 由谁书写、有无见证人、能否办理公证 | 自书遗嘱要求亲笔书写、签名并注明年月日；代书、打印、录音录像、口头均需两个以上适格见证人并按法定方式签署或记录；公证遗嘱经公证机构办理 |
| 采用打印方式书写 | 是否在每一页签名并注明日期 | 遗嘱人和见证人应在遗嘱每一页签名，只在末页签名的存在被认定无效的风险 |
| 口头遗嘱 | 是否处于危急情况、危急情况是否已消除 | 危急情况消除后能够以书面或录音录像形式立遗嘱的，所立口头遗嘱无效 |
| 确定见证人 | 是否属于无见证能力人、继承人、受遗赠人或有利害关系的人 | 上述人员不能作为见证人，继承人、受遗赠人的债权人、债务人、共同经营的合伙人同样视为有利害关系 |
| 存在多份遗嘱 | 各份遗嘱的形式是否合法、订立时间先后如何 | 形式合法的数份遗嘱内容相抵触的，以最后的遗嘱为准；公证遗嘱不再享有优先效力；实施相反行为视为撤回相关内容 |
| 判断遗嘱效力 | 立遗嘱时有无行为能力、是否受欺诈胁迫、有无伪造篡改 | 无或限制民事行为能力人所立的遗嘱无效，受欺诈、胁迫所立的遗嘱无效，伪造的遗嘱无效，篡改的内容无效；未保留必留份的应先留出必要遗产 |

## 六、操作步骤

1. 先确定拟采用的形式，并核对这种形式的全部法定要件
2. 逐项自查：签名主体、签名位置、日期是否完整、见证人是否适格
3. 打印或代书形成的遗嘱，逐一核对每一页是否签名并注明日期
4. 核查见证人资格，排除继承人、受遗赠人及其债权人、债务人与合伙人
5. 确认立遗嘱时的民事行为能力，必要时保留病历或诊断材料
6. 清点是否存在多份遗嘱，按时间排序并核对相互抵触的部分
7. 核对是否需为缺乏劳动能力又没有生活来源的继承人保留必要遗产

## 七、常见误区

- 电脑打印全文后只签一个名，却按自书遗嘱使用
- 打印遗嘱只在最后一页签名，忽略每一页签名注日期的要求
- 让继承人、受遗赠人或者他们的债主、合伙人担任见证人
- 认为公证遗嘱效力最高，仍按旧规则判断多份遗嘱的效力
- 遗嘱中处分了配偶的份额或者他人财产，未意识到该部分无效
- 把口头遗嘱当成长期有效的形式，忽略危急情况消除后即无效

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
