# 检查表

## 事实与材料自查

- [ ] 房屋的产权状态是否已确认
- [ ] 首付来源与凭证是否齐全
- [ ] 是否查清贷款余额与剩余期限
- [ ] 登记情况是否核实，是否登记了对方名字
- [ ] 是否有书面的赠与约定或财产约定
- [ ] 婚后共同还贷的流水是否完整导出
- [ ] 房屋现值是否确定，是否需要评估
- [ ] 房屋归一方后，贷款人变更是否同步办理

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
