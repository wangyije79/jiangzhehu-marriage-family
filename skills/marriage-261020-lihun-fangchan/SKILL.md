# 离婚时的房产分割

> 按揭房、一方首付与父母出资房

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「婚前首付婚后还贷的房子怎么分？」「按揭房离婚怎么处理？」

**什么时候会用到它**：

- 婚前首付婚后还贷的房子怎么分
- 按揭房离婚怎么处理
- 父母出资的房子离婚归谁

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
婚前首付婚后还贷的房子怎么分？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于离婚时的房屋分割争议，包括婚前首付婚后共同还贷的房屋、尚未取得所有权或完全所有权的按揭房、婚前承租婚后共同购买的房屋、以一方父母名义参加房改的房屋，以及父母出资购房的归属与补偿认定。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 婚前首付、婚后共同还贷、登记在首付方名下 | 双方能否达成协议 | 协议不成的，可以判决房屋归登记一方，剩余贷款为其个人债务，并对另一方补偿共同还贷款项及对应增值 |
| 房屋尚未取得所有权或完全所有权 | 产权状态是否明确 | 不宜判决归属，先判决由当事人使用；取得完全所有权后可另行起诉 |
| 双方都主张房屋所有权 | 是否同意竞价 | 同意竞价的应当准许；一方主张的按评估价取得并补偿；都不主张的拍卖变卖后分割价款 |
| 父母婚前出资 | 父母是否明确表示赠与双方 | 默认认定为对自己子女个人的赠与，明确表示赠与双方的除外 |
| 父母婚后全额出资 | 赠与合同是否明确约定只赠与自己子女一方 | 有约定按约定；无约定或约定不明的，可以判决房屋归出资人子女一方，并酌定是否补偿及数额 |
| 父母部分出资或双方父母出资 | 出资来源与比例、有无约定 | 有约定按约定；无约定时以出资来源及比例为基础判决归属并合理补偿 |

## 六、操作步骤

1. 先判断房屋的产权状态：已办证、未办证还是部分产权
2. 核实首付与各笔出资的来源、时间与凭证
3. 核查登记情况：登记在谁名下，是否加名，是否有共有约定
4. 查找是否存在书面赠与约定或财产约定
5. 计算婚后共同还贷总额及其对应的增值部分
6. 对现值有争议的，申请评估机构按市场价格评估
7. 房屋判归一方且贷款随之转移的，同步办理贷款人变更手续

## 七、常见误区

- 以为婚后一起还贷房子就有自己一半，忽视登记与首付归属
- 以为剩余贷款要双方共同偿还，忽略可判归登记方个人债务
- 未办证的房屋硬要争归属，结果只拿到使用权
- 以为父母出资一律算共同财产，忽略婚前婚后的区别
- 事后补写赠与说明，被质疑效力
- 竞价取得房屋后无力支付补偿款，陷入新的纠纷

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
