# 抚养费与探望权

> 抚养费标准、变更与探望权执行

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「抚养费一般给多少？」「抚养费能要求增加吗？」

**什么时候会用到它**：

- 抚养费一般给多少
- 抚养费能要求增加吗
- 对方不让看孩子怎么办

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
抚养费一般给多少？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于离婚后子女抚养费的数额确定、给付方式与给付期限的判断，也适用于抚养费的增加与欠付追索，以及探望权的行使方式、单独起诉、中止探望与拒不协助的救济。同时覆盖离婚协议约定一方全担、对方以改姓为由拒付、探望受阻时如何固定证据等常见问题。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 确定抚养费数额 | 有无固定收入、负担几个子女、当地生活水平如何 | 有固定收入的按月总收入的百分之二十至三十给付，负担两个以上子女的一般不超过百分之五十；无固定收入按当年总收入或同行业平均收入参照确定 |
| 明确抚养费范围 | 支出属于生活费、教育费还是医疗费 | 三类费用均包含在抚养费内，正常范围内的日常支出不再另行主张 |
| 判断给付方式与期限 | 对方有无经济收入、子女是否满十八周岁 | 原则上定期给付，有条件的可一次性给付；无收入或下落不明可用财物折抵；期限一般至子女十八周岁 |
| 离婚协议约定一方全担 | 直接抚养方经济状况是否显著变化、子女必要合理费用是否显著增加 | 约定对双方有约束力，但出现显著变化时子女仍可请求另一方支付抚养费 |
| 要求增加抚养费 | 是否符合原定数额不足以维持当地生活水平、子女患病上学实际需要增加等情形 | 符合法定情形的应予支持，程序上应当另行提起诉讼 |
| 主张探望权受阻 | 现有文书是否涉及探望权、对方是拒不协助还是存在不利于子女身心健康的情形 | 文书已涉及的走执行并可采取拘留、罚款等措施；未涉及的单独起诉；存在不利情形的申请中止探望 |

## 六、操作步骤

1. 先确认身份关系与现有文书：离婚协议、判决书、调解书里关于子女的条款
2. 核算抚养费基数：固定收入按月总收入，无固定收入按当年总收入或行业平均收入
3. 核对当地上一年度居民人均消费支出，判断原定数额是否明显偏低
4. 统计子女近一年的生活、教育、医疗实际支出，形成台账与票据集
5. 判断诉讼路径：增加抚养费与变更抚养关系均需另行起诉
6. 探望权受阻的，先固定拒绝协助的证据，再选择执行或单独起诉
7. 主张中止探望的，准备不利于子女身心健康的具体事实材料

## 七、常见误区

- 把百分之二十至三十当成必须照搬的固定比例，忽略当地生活水平与对方负担能力
- 已有生效文书却直接申请执行要求加钱，未意识到增加抚养费需另行起诉
- 以为对方改了孩子姓氏就可以停付抚养费
- 只主张未来的抚养费，遗漏已经欠付的部分
- 要求强制执行孩子的人身，忽略不得对子女人身强制执行的限制
- 把中止探望当成长期手段，忽略情形消失后应当恢复探望

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
