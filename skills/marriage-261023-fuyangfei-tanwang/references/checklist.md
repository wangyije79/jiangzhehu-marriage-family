# 检查表

## 事实与材料自查

- [ ] 是否已核对离婚协议或生效文书中关于抚养费与探望权的约定
- [ ] 对方收入线索是否已固定（工资流水、社保、公积金、个税记录）
- [ ] 子女近一年生活、教育、医疗支出是否有台账与票据支撑
- [ ] 当地居民人均消费支出数据是否已查询并留档
- [ ] 增加抚养费的主张是否落在法定三种情形之内
- [ ] 探望的具体时间、地点、接送方式是否明确可执行
- [ ] 对方拒绝协助探望的证据是否保留了原始载体
- [ ] 涉及中止探望的，是否有不利于子女身心健康的具体事实

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
