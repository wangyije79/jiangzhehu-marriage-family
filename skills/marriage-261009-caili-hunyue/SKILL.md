# 彩礼与婚约财产

> 彩礼返还三情形、范围界定与恋爱期间大额转账

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「什么情况下彩礼要返还？」「恋爱期间的转账分手能要回来吗？」

**什么时候会用到它**：

- 什么情况下彩礼要返还
- 恋爱期间的转账分手能要回来吗
- 哪些钱不算彩礼

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
什么情况下彩礼要返还？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于彩礼范围的认定、彩礼返还的条件与比例判断、恋爱期间给付财物性质的区分，也适用于婚约财产纠纷中原被告的确定与证据准备。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 双方未办理结婚登记 | 是否已共同生活、彩礼实际使用与嫁妆情况 | 可以请求返还，但返还与否及比例需结合共同生活情况、孕育情况、双方过错、当地习俗综合确定，并非一律全额返还 |
| 已办理结婚登记且共同生活 | 共同生活时间长短、彩礼数额是否过高 | 一般不予支持返还；共同生活时间较短且彩礼数额过高的，可按比例返还 |
| 登记但确未共同生活 | 是否有证据证明未共同生活 | 解释（一）第五条规定应予支持返还，且应以离婚为条件 |
| 婚前给付导致给付人生活困难 | 给付方家庭经济状况与当地生活水平 | 解释（一）第五条规定应予支持返还，应以离婚为条件 |
| 恋爱期间的转账 | 有无借贷合意、是否以结婚为目的、金额大小 | 有借贷合意的按民间借贷处理；无借贷合意且数额大、符合习俗的按彩礼处理；日常消费性支出与小额礼物不属于彩礼，一般不予返还 |
| 父母参与给付或接收 | 谁是实际给付人、实际接收人 | 婚约财产纠纷中，实际给付彩礼的父母可作为共同原告，实际接收彩礼的父母可作为共同被告 |

## 六、操作步骤

1. 梳理全部给付记录：逐笔列出时间、金额、方式、备注、给付人与接收人
2. 区分性质：大额且以结婚为目的的归入彩礼；借贷合意明确的归入借款；日常小额支出单独归类
3. 归集用途证据：彩礼用于共同生活、置办嫁妆、举办婚礼的支出凭证
4. 整理嫁妆清单与价值凭证
5. 保留能体现缔结婚姻目的的沟通记录（谈婚论嫁、商议婚事的对话）
6. 现金给付的，尽早固定在场人陈述、媒人证言等补强证据
7. 确定当事人：涉及父母给付或接收的，明确是否列为共同原告或被告

## 七、常见误区

- 认为没领证就一定能全额返还
- 认为领了证就一定不用返还
- 把节日红包、日常消费一并主张为彩礼
- 只保留转账金额、不保留备注与聊天记录
- 忽略嫁妆与实际使用情况对返还比例的影响
- 起诉时未将实际给付或接收彩礼的父母列为当事人

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
