# 检查表

## 事实与材料自查

- [ ] 是否已逐笔列明给付时间、金额、方式与备注
- [ ] 大额给付与日常小额支出是否已分开归集
- [ ] 是否保留了体现结婚目的的沟通记录
- [ ] 彩礼的实际用途是否有凭证支撑
- [ ] 嫁妆情况与价值是否已梳理
- [ ] 现金给付部分是否有补强证据
- [ ] 是否已确定父母在纠纷中的当事人地位
- [ ] 是否存在登记后共同生活时间明显偏短的事实

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
