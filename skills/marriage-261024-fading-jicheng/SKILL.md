# 法定继承

> 继承顺序、份额确定与代位继承

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「法定继承的顺序是什么？」「遗产一般怎么分？」

**什么时候会用到它**：

- 法定继承的顺序是什么
- 遗产一般怎么分
- 孙子女能代位继承吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
法定继承的顺序是什么？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于法定继承的顺序判断、继承人范围认定与份额分配，也适用于代位继承与转继承的区分、丧偶儿媳女婿的第一顺序资格、养子女与继子女的继承权、继承人以外的人分得适当遗产等常见争议。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 确定有无第一顺序继承人 | 配偶、子女、父母是否有人健在 | 有第一顺序继承人的，第二顺序继承人不参与继承；无第一顺序继承人的，由第二顺序继承人继承 |
| 判断子女、父母、兄弟姐妹的范围 | 是否养子女、有扶养关系的继子女或继父母 | 有扶养关系的继子女、继父母、继兄弟姐妹均计入范围，无扶养关系的相互之间不是法定继承人 |
| 存在丧偶儿媳或丧偶女婿 | 是否对公婆、岳父母尽了主要赡养义务、是否再婚 | 尽了主要赡养义务的作为第一顺序继承人，是否再婚不影响，且不影响其子女代位继承 |
| 子女先于被继承人死亡，或继承人于继承开始后、遗产分割前死亡 | 死亡时点落在哪一个阶段 | 前者的由被继承人子女的直系晚辈血亲代位继承，代位人一般只能继承被代位人有权继承的份额；后者属于转继承，该份额转给继承人自己的继承人 |
| 继承人丧失继承权 | 是否存在法律规定的丧失事由 | 其晚辈直系血亲不得代位继承；代位人符合特定条件时可适当分给遗产 |
| 确定同一顺序的份额 | 各继承人的经济状况、扶养义务履行情况 | 一般均等；困难者应照顾，尽主要扶养义务者可多分，不尽义务者应当不分或少分，协商同意可不均等 |

## 六、操作步骤

1. 确认继承开始时间与被继承人的亲属关系全貌
2. 列出第一顺序、第二顺序继承人的完整名单，不遗漏非婚生子女与养继子女
3. 核查是否存在需要排除的人：无扶养关系的继亲属、丧失继承权的人
4. 核对被代位人与被继承人的死亡时间先后，区分代位继承与转继承
5. 收集扶养事实证据：经济来源、劳务扶助、医疗护理记录
6. 确定份额：先按均等划分，再逐人核对其属于应当照顾、可以多分还是应当少分
7. 先协商并形成书面分割协议，协商不成再申请调解或起诉

## 七、常见误区

- 以为第二顺序继承人总能分到一部分，忽略第一顺序的排他性
- 把无扶养关系的继父母、继子女当成法定继承人
- 把代位继承与转继承混为一谈，弄错主张的份额基础
- 忽略养子女与生子女之间可互为第二顺序继承人，与亲兄弟姐妹之间却不再互为继承人
- 只讲谁照顾得多，拿不出付款凭证与护理记录
- 一上来就起诉，忽略协商与人民调解的前置做法

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
