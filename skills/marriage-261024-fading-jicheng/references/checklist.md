# 检查表

## 事实与材料自查

- [ ] 第一顺序与第二顺序继承人的名单是否完整
- [ ] 非婚生子女、养子女、有扶养关系的继子女是否已纳入范围
- [ ] 收养关系、扶养关系的证明材料是否齐备
- [ ] 丧偶儿媳或丧偶女婿尽主要赡养义务的事实是否有证据
- [ ] 被代位人与被继承人的死亡时间先后是否有证明
- [ ] 各继承人的经济状况与劳动能力是否已逐一核实
- [ ] 赡养与扶养事实是否有付款凭证、陪护记录支撑
- [ ] 分割协议是否写明每个人分得的具体财产与份额

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
