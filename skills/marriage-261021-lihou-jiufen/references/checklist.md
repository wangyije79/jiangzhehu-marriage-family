# 检查表

## 事实与材料自查

- [ ] 是否已判断清楚适用哪一类法律依据
- [ ] 时效期间与起算点是否已核算
- [ ] 发现线索的时间是否已用证据固定
- [ ] 财产线索是否具体到账户、房产或股权
- [ ] 是否核查过离婚协议中的财产条款与兜底条款
- [ ] 是否评估过申请财产保全的必要性
- [ ] 取证方式是否合法，是否存在侵权风险
- [ ] 是否需要在诉前申请调查取证

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
