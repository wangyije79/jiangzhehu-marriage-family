# 离婚后财产纠纷

> 漏分财产、发现隐藏财产与协议反悔

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「离婚后发现对方藏了钱怎么办？」「离婚协议能不能撤销？」

**什么时候会用到它**：

- 离婚后发现对方藏了钱怎么办
- 离婚协议能不能撤销
- 离婚后财产纠纷有诉讼时效吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
离婚后发现对方藏了钱怎么办？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于离婚后产生的财产类争议，包括发现对方隐藏、转移财产后的再次分割，离婚时未处理财产的分割请求，离婚协议财产条款的效力与撤销，以及相关请求的诉讼时效起算与程序安排。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 离婚后发现对方有隐藏、转移、变卖、毁损、挥霍财产或伪造债务行为 | 能否提供转移行为的具体线索与证据 | 可以起诉请求再次分割，并请求对该方少分或者不分；时效三年，自发现之日起算 |
| 离婚时只是漏分了财产，不存在上述行为 | 该财产是否确属离婚时未涉及 | 可以起诉请求分割，经审查确属未涉及的，法院应当依法予以分割 |
| 协议离婚后对财产分割反悔 | 订立协议时是否存在欺诈、胁迫等情形 | 存在法定情形的可能被撤销；仅以分得不公或事后后悔为由的，应当驳回 |
| 登记离婚后被主张双方意思表示虚假 | 是否能证明离婚本身存在虚假意思表示 | 请求确认离婚无效的，人民法院不予支持 |
| 离婚协议约定将财产给予子女后一方反悔 | 财产权利是否已经转移 | 转移前请求撤销的，不予支持，另一方同意的除外 |
| 发现财产线索但尚未起诉 | 是否存在继续转移的风险 | 起诉时同步申请财产保全，避免边谈边转移 |

## 六、操作步骤

1. 先判断属于再次分割、未处理财产分割，还是协议撤销三类情形中的哪一类
2. 按对应情形确定时效期间与起算点
3. 固定发现财产线索的时间与方式，留存查询与沟通记录
4. 按财产类型整理线索清单，越具体越好
5. 在时效内起诉，必要时申请法院调查取证
6. 评估对方继续转移的风险，同步申请财产保全
7. 起诉前核查协议中是否有未列明财产的兜底条款

## 七、常见误区

- 把“发现之日”误当成“离婚之日”，错过时效
- 以为离婚时漏分的财产就归对方了
- 仅因为分得不公平就请求撤销离婚协议
- 以“假离婚”为由请求确认离婚无效
- 发现线索后只谈判不保全，财产被继续转移
- 用侵入账号、翻找手机等违法方式取证

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
