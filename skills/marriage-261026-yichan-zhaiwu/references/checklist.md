# 检查表

## 事实与材料自查

- [ ] 资产清单是否逐项核实了取得时间、登记名义与资金来源
- [ ] 夫妻共同财产的一半是否已分出给配偶
- [ ] 家庭共有财产中他人的部分是否已先予分出
- [ ] 赔偿金、抚恤金、指定受益保险金等是否已排除在遗产之外
- [ ] 税款与债务清单是否完整，有无凭证支撑
- [ ] 清偿上限是否按所得遗产的实际价值核算
- [ ] 胎儿份额与必留份是否已预留
- [ ] 放弃继承的书面表示是否已送达并保留凭证

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
