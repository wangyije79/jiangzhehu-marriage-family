# 遗产范围与债务清偿

> 遗产界定、限定继承与共同财产析出

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「哪些财产算遗产？」「继承遗产要还死者债务吗？」

**什么时候会用到它**：

- 哪些财产算遗产
- 继承遗产要还死者债务吗
- 放弃继承怎么办

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
哪些财产算遗产？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于遗产范围的界定与夫妻共同财产的析出，也适用于税款与债务的清偿顺序、限定继承的界限、放弃继承的形式与时间要求、胎儿与必留份的保留，以及无人继承遗产的归属处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 界定遗产范围 | 财产是否属于被继承人个人、是否合法取得 | 遗产是死亡时遗留的个人合法财产，依法律或性质不得继承的除外 |
| 财产属于夫妻共同所有 | 有无财产约定、财产取得时间 | 遗产分割时应先将共同所有财产的一半分出为配偶所有，家庭共有财产中他人的部分同样先分出 |
| 存在按性质不能继承的财产 | 是否为赔偿金、抚恤金、指定受益保险金或人身专属性权利 | 上述财产不作为遗产处理，按各自的发放对象或权利归属另行处理 |
| 确定债务清偿责任 | 继承人所继承遗产的实际价值是多少 | 继承人以所得遗产实际价值为限清偿税款和债务，超过部分不强制清偿，放弃继承的可不负清偿责任 |
| 法定继承与遗嘱继承、遗赠并存 | 各类继承方式分得的遗产数额 | 由法定继承人清偿；超过法定继承遗产实际价值部分，由遗嘱继承人和受遗赠人按比例以所得遗产清偿 |
| 决定是否放弃继承 | 是否在遗产处理前、能否以书面形式作出 | 应在继承开始后、遗产分割前以书面形式向遗产管理人或继承人表示；致其不能履行法定义务的放弃无效；效力追溯到继承开始 |

## 六、操作步骤

1. 列出全部资产并逐项核实取得时间、登记名义与资金来源
2. 析出配偶的一半与家庭共有财产中他人的部分，确定遗产净额
3. 剔除按性质不能继承的财产，标注各自的处理路径
4. 清理被继承人的税款与债务，形成债务清单并核对凭证
5. 核算遗产实际价值，据此确定继承人的清偿上限
6. 核对是否需要为胎儿保留份额、为缺乏劳动能力又无生活来源的继承人留出必要遗产
7. 决定接受或放弃继承：放弃须在遗产处理前以书面形式作出并留存送达凭证

## 七、常见误区

- 把夫妻共同财产整体当作遗产分配，遗漏配偶应得的一半
- 把死亡赔偿金、抚恤金当遗产分配，忽略其按身份发放的性质
- 以为继承了遗产就要替死者清偿全部债务
- 不清楚法定继承人与遗嘱继承人、受遗赠人之间的清偿顺序
- 口头表示放弃继承，事后拿不出任何书面或笔录材料
- 遗产已经分割完毕才提出放弃，误以为仍是放弃继承权

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
