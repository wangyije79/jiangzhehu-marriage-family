# 婚内财产分割与保全

> 婚内析产、转移财产与财产保全

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「不离婚能分割共同财产吗？」「发现对方转移财产怎么办？」

**什么时候会用到它**：

- 不离婚能分割共同财产吗
- 发现对方转移财产怎么办
- 怎么申请财产保全

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
不离婚能分割共同财产吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于婚姻关系存续期间请求分割共同财产的法定情形判断、隐藏转移变卖毁损挥霍共同财产与伪造共同债务的认定、直播打赏与为婚外情目的赠与共同财产的处理，以及离婚后发现财产转移的再次分割与时效计算、财产保全的时点选择、标的确定与担保数额争取。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 婚内请求分割共同财产 | 是否属于民法典第一千零六十六条规定的两种情形 | 属于两种情形之一的可获支持，否则不予支持 |
| 一方大额打赏网络主播 | 是否未经同意、明显超出家庭一般消费水平、严重损害共同财产利益 | 可认定为挥霍，支持婚内分割或者离婚时少分不分 |
| 一方为婚外情等目的赠与共同财产 | 是否违反夫妻忠实义务、是否以明显不合理价格处分 | 可主张该行为违背公序良俗无效，并请求分割或者少分不分 |
| 离婚后发现对方曾经转移财产 | 自发现之日起三年内是否已经起诉 | 在三年内可以请求再次分割夫妻共同财产 |
| 婚内拟申请财产保全 | 能否提供具体财产线索与担保 | 可以在可能造成的损失范围内确定合理的财产担保数额 |
| 担心对方继续处分财产 | 是否需要诉前保全、能否在期限内起诉 | 诉前保全后应在法定期限内起诉，否则保全会被解除 |

## 六、操作步骤

1. 先定性：把可疑行为对应到隐藏、转移、变卖、毁损、挥霍或者伪造债务
2. 同步取证：导出银行与支付平台流水，查询不动产、车辆与股权登记
3. 算清金额：统计异常支出的总额、时间、频次与接收方
4. 判断路径：选择婚内分割之诉，或者留待离婚时主张少分不分
5. 准备保全：列出财产线索清单，确定保全标的与金额范围
6. 落实担保：选择现金担保或者保全责任保险保函，争取合理担保数额
7. 注意时效：离婚后再次分割的，自发现之日起三年内起诉

## 七、常见误区

- 以为不离婚就完全不能分财产，忽略两种法定情形
- 把打赏或者赠与第三人的行为只当成感情问题，错过财产救济
- 只收集证据不申请保全，等对方把财产处分完毕
- 保全标的写得过于模糊，法院无法执行
- 诉前保全后忘记在法定期限内起诉，导致保全被解除
- 离婚多年后才发现转移财产，忽略三年时效自发现之日起算

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
