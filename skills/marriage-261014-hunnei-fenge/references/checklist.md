# 检查表

## 事实与材料自查

- [ ] 是否已确认行为落入法定情形，能否说明损害程度
- [ ] 打赏或者赠与的总额是否已统计，能否与家庭收入水平对比
- [ ] 资金最终流向是否查清，接收方身份是否明确
- [ ] 银行流水、支付账单、聊天记录是否已经完整导出
- [ ] 不动产与股权的登记、变更信息是否已经查询
- [ ] 是否已确定保全标的并备齐财产线索材料
- [ ] 担保方式与担保数额是否已经确定
- [ ] 离婚后发现新线索的，是否计算过三年时效的届满日

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
