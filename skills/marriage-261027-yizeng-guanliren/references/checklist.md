# 检查表

## 事实与材料自查

- [ ] 处分文件的性质是否已判断清楚（遗嘱继承还是遗赠）
- [ ] 是否存在遗赠扶养协议，与遗嘱有无抵触
- [ ] 受遗赠人是否已知悉受遗赠事实、六十日如何起算
- [ ] 接受遗赠的书面文件是否写明身份、意思表示与日期
- [ ] 送达凭证是否留存（快递面单、电子邮件、签收记录）
- [ ] 遗产的税款与债务清单是否已核对
- [ ] 遗产管理人的人选是否确定，有无争议
- [ ] 管理人的职责范围与报酬是否已书面明确

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
