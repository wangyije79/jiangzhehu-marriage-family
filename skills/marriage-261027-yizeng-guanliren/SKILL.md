# 遗赠与遗产管理人

> 遗赠要件、接受期限与遗产管理人职责

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「遗赠和遗嘱继承差在哪？」「受遗赠人多久不表态算放弃？」

**什么时候会用到它**：

- 遗赠和遗嘱继承差在哪
- 受遗赠人多久不表态算放弃
- 遗产管理人做什么

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
遗赠和遗嘱继承差在哪？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于遗嘱继承与遗赠的区分、遗赠扶养协议与遗嘱抵触时的处理、受遗赠人接受或放弃的期限与方式，也适用于遗产管理人的产生、指定、六项职责、责任承担与报酬约定等常见问题。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 判断财产处分的性质 | 受益人是法定继承人还是其他人 | 指定法定继承人中的一人或数人继承的为遗嘱继承；赠与国家、集体或法定继承人以外的组织、个人的为遗赠 |
| 确定各类文件的适用顺序 | 是否存在遗赠扶养协议、遗嘱或遗赠 | 有协议的按协议办理，其次按遗嘱继承或遗赠办理，均无的按法定继承办理；协议与遗嘱抵触的，按协议处理 |
| 受遗赠人未及时表态 | 是否在知道受遗赠后六十日内作出表示 | 到期没有表示的视为放弃受遗赠，须以可证明的方式及时表态 |
| 遗赠扶养协议一方不履行 | 是扶养方不履行还是遗赠人不履行 | 扶养方无正当理由不履行导致协议解除的，不能享有受遗赠权利且已付供养费用一般不予补偿；遗赠人不履行的应偿还已付供养费用 |
| 确定遗产管理人 | 有无遗嘱执行人、继承人能否推选出人选 | 遗嘱执行人优先；无则由继承人及时推选，未推选由继承人共同担任；无继承人或均放弃继承的由民政部门或村民委员会担任 |
| 对管理人确定有争议 | 利害关系人之间能否达成一致 | 可以向人民法院申请指定遗产管理人 |

## 六、操作步骤

1. 先看处分文件，判断受益人是法定继承人还是第三人，确定规则路径
2. 核对有无遗赠扶养协议，并比对协议与遗嘱是否存在抵触
3. 属于遗赠的，从知道受遗赠之日起计算六十日并立即书面表态
4. 表态文件写明身份、遗嘱情况、接受的意思表示与日期并留存送达凭证
5. 核对遗产的税款与债务，明确执行遗赠不得妨碍清偿
6. 确定遗产管理人：有遗嘱执行人的由其担任，否则推动推选或申请法院指定
7. 要求管理人制作遗产清单、报告情况并采取措施防止遗产毁损灭失

## 七、常见误区

- 把遗赠当成遗嘱继承，以为不表态也自动取得
- 从被继承人死亡之日起算六十日，弄错起算点
- 只用口头或者聊天里的一句感谢表示接受，拿不出证据
- 忽略遗赠扶养协议优先于遗嘱的效力顺序
- 以为受遗赠人拿到的就是遗嘱上写的数额，忽略债务清偿
- 对遗产管理人的确定有争议时，迟迟不申请法院指定

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
