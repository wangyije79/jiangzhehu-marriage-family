# 检查表

## 事实与材料自查

- [ ] 是否已列明每一笔债务的发生时间、金额与出借人
- [ ] 借条或者合同上是否有自己的签字或者事后认可的记录
- [ ] 资金去向是否已核对，能否判断实际用途
- [ ] 是否已区分哪些债务由债权人举证、哪些需要自己举证
- [ ] 是否存在赌博、吸毒、串通虚构等法定排除情形
- [ ] 离婚协议中的债务承担条款是否逐笔写明
- [ ] 承担清偿后是否保留了转账凭证与收据等追偿证据
- [ ] 是否已评估财产分割条款被债权人主张撤销的风险

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
