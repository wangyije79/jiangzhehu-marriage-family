# 夫妻共同债务

> 共债共签、日常生活需要与举证责任

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「配偶在外面借钱我要还吗？」「哪些债务算夫妻共同债务？」

**什么时候会用到它**：

- 配偶在外面借钱我要还吗
- 哪些债务算夫妻共同债务
- 离婚协议约定债务归一方有效吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
配偶在外面借钱我要还吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于配偶以个人名义所负债务的性质判断、家庭日常生活需要与共同生产经营的界定、超出日常需要的大额债务的举证责任分配，以及离婚协议或者生效法律文书中债务承担约定对债权人的效力、履行后的追偿路径，和净身出户式约定被债权人主张撤销的风险评估。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 配偶以个人名义对外借款 | 有无双方共同签名或者事后追认 | 存在共同意思表示的，属于夫妻共同债务 |
| 一方以个人名义借款用于日常开支 | 是否属于家庭日常生活需要的范围 | 范围内的属于共同债务；超出范围按大额债务规则判断 |
| 一方以个人名义大额借款 | 债权人能否证明用于共同生活或者共同生产经营 | 能证明的属于共同债务；不能证明的不属于 |
| 债务发生在婚前 | 债权人能否证明用于婚后家庭共同生活 | 原则上不认定为夫妻共同债务 |
| 债务源于赌博、吸毒或者存在串通虚构 | 是否有证据证实上述情形 | 依法不予认定为夫妻共同债务 |
| 离婚协议约定债务由一方承担 | 债权人是否同意该债务转移 | 对债权人不当然生效；承担清偿的一方可向另一方追偿 |

## 六、操作步骤

1. 先确定债务发生时间：区分婚前债务与婚内债务
2. 判断有无共同意思表示：核查借条、合同、聊天记录中的签字与认可
3. 判断用途：核对资金去向，区分家庭日常需要、共同生活与共同生产经营
4. 区分举证责任：大额债务由债权人举证，婚前个人债务同样由债权人举证
5. 识别排除情形：赌博吸毒、串通虚构、明显用于个人事务的债务
6. 评估离婚协议条款：明确对内追偿权与对外效力，评估被撤销的风险
7. 整理材料清单：借条、转账记录、资金去向凭证、还款凭证与沟通记录

## 七、常见误区

- 随手在对方借条上签字或者写备注，把自己变成共同债务人
- 用自己账户替对方的个人债务还款，可能被认定为事后追认
- 收到起诉后不到庭，导致缺席判决认定需要共同承担
- 以为离婚协议约定债务归一方就能完全隔离债权人的追索
- 把婚前个人债务当然当成需要共同承担的债务
- 忽略共同债务在一方死亡后仍由生存一方承担清偿责任

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
