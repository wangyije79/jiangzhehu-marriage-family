# 离婚财产分割规则

> 照顾原则、隐藏转移少分与协议处理

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「离婚财产一般怎么分？」「对方转移财产会少分吗？」

**什么时候会用到它**：

- 离婚财产一般怎么分
- 对方转移财产会少分吗
- 家务劳动能要求补偿吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
离婚财产一般怎么分？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于离婚时的夫妻共同财产分割，包括共同财产与个人财产的界定、分割原则与份额调整、隐藏转移财产与挥霍行为的处理、婚内分割共同财产的路径，以及家务劳动补偿的主张与数额认定。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 确定某项财产是否可分割 | 属于婚姻关系存续期间所得，还是一方的婚前财产等个人财产 | 共同财产纳入分割范围，个人财产不参与分割 |
| 个人财产在婚后产生了收益 | 收益是孳息、自然增值，还是投资经营所得 | 除孳息和自然增值外，应认定为夫妻共同财产 |
| 双方存在书面财产约定 | 约定是否采用书面形式 | 有书面约定的按约定处理，没有或约定不明的适用法定规则 |
| 发现对方隐藏、转移、变卖、毁损、挥霍财产或伪造债务 | 能否证明行为与涉及财产 | 离婚分割时可以少分或者不分；婚内可先请求分割，离婚后可再次起诉分割 |
| 一方长期负担较多家庭义务 | 是否有证据证明投入的时间、精力及对双方的影响 | 可以在分割之外请求补偿，数额由双方协议或法院酌定 |
| 财产情况掌握不全 | 能否提供明确的财产线索 | 起诉时可以申请法院调查取证，并考虑申请财产保全 |

## 六、操作步骤

1. 先列财产清单，把共同财产与个人财产分栏
2. 逐项标注来源、出资时间、登记情况与现有价值
3. 核查是否存在书面财产约定，确认适用约定还是法定规则
4. 排查对方是否存在隐藏、转移、变卖、毁损、挥霍或伪造债务的行为
5. 对不掌握的财产列出线索，起诉时申请调查并考虑财产保全
6. 长期负担较多家庭义务的，同步准备补偿请求的证据
7. 在诉讼请求中同时写明分割方案、补偿请求与照顾无过错方的理由

## 七、常见误区

- 把婚前个人财产当成共同财产主张分割
- 以为个人财产在婚后的所有增值都属于共同财产
- 只主张多分财产，遗漏家务劳动补偿这项独立请求权
- 发现对方转移财产却不及时申请保全，判决后执行困难
- 离婚时未处理的财产就此放弃，忽略可以另行起诉分割
- 口头财产约定无法举证，导致约定不被认可

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
