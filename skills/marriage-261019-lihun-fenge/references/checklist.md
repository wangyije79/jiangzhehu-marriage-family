# 检查表

## 事实与材料自查

- [ ] 财产清单是否覆盖房产、存款、股权、车辆、公积金与养老金
- [ ] 每项财产是否标注了来源与登记情况
- [ ] 是否核查过书面财产约定
- [ ] 个人财产与共同财产是否已区分清楚
- [ ] 是否发现对方有异常大额转账或财产变更记录
- [ ] 是否考虑申请财产保全
- [ ] 是否准备家务补偿的证据材料
- [ ] 是否评估过自身是否存在法定过错

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
