# 检查表

## 事实与材料自查

- [ ] 双方是否确实自愿离婚，有无一方被胁迫的情形
- [ ] 子女抚养安排是否写明抚养权、抚养费与探望方式
- [ ] 财产是否逐项列明，包括房产、车辆、存款、股权与公积金
- [ ] 债务是否逐笔写明金额、债权人与承担方
- [ ] 是否已约定未披露财产的处理方式
- [ ] 三个关键日期是否已经记录并设置提醒
- [ ] 领证所需的证件材料是否已按登记机关要求备齐
- [ ] 是否确认领证之后婚姻关系才解除

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
