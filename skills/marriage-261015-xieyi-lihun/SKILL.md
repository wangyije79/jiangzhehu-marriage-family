# 协议离婚与冷静期

> 冷静期规则、离婚协议效力与登记流程

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「离婚冷静期怎么算？」「离婚协议签了能反悔吗？」

**什么时候会用到它**：

- 离婚冷静期怎么算
- 离婚协议签了能反悔吗
- 协议离婚要走哪些流程

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
离婚冷静期怎么算？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于协议离婚的申请条件与办理流程、离婚冷静期与领证期的期限计算、离婚协议中自愿离婚意思表示与子女抚养、财产、债务三项内容的拟定，以及离婚未成时财产处理协议的效力、离婚登记后对财产分割反悔的救济、约定将财产给予子女后请求撤销的处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 双方自愿离婚 | 子女抚养、财产、债务三项内容是否均已协商一致 | 谈拢的走协议离婚；任意一项谈不拢的走诉讼离婚 |
| 婚姻登记机关收到离婚登记申请 | 是否在三十日之内 | 期间任何一方可以单方面撤回申请 |
| 冷静期届满 | 是否在随后三十日内由双方亲自申领离婚证 | 申领的发给离婚证；未申领的视为撤回离婚登记申请 |
| 签了以协议离婚为条件的财产处理协议 | 离婚是否最终办成 | 离婚未成的，该协议在离婚诉讼中不生效，一方可以反悔 |
| 协议离婚后就财产分割反悔 | 订立协议时是否存在欺诈、胁迫等情形 | 存在欺诈、胁迫的可以请求撤销；不存在的驳回诉讼请求 |
| 离婚协议约定将财产给予子女 | 财产权利是否已转移、另一方是否同意 | 一方不得单方撤销，除存在欺诈、胁迫或者另一方同意 |

## 六、操作步骤

1. 先确认路径：核对子女抚养、财产、债务三项内容是否全部协商一致
2. 拟定协议：写明自愿离婚的意思表示，逐项列明子女、财产、债务安排
3. 提交申请：双方亲自到婚姻登记机关申请离婚登记
4. 记好第一个三十天：冷静期内任何一方可以撤回，注意对方是否撤回
5. 记好第二个三十天：双方亲自到场申请发给离婚证
6. 领证归档：领取离婚证并妥善保存，确认婚姻关系解除
7. 留存材料：协议原件、申请与领证凭证、财产与债务凭证一并归档

## 七、常见误区

- 以为签完离婚协议就算离婚，忽略登记与领证环节
- 把冷静期的三十天与领证期的三十天混为一谈
- 冷静期届满后超过三十天未申领，导致视为撤回
- 离婚协议写得过于笼统，事后无法处理对方隐瞒的财产
- 以为离婚登记后觉得分得少就能撤销财产分割协议
- 以为约定给子女的财产在过户之前可以随时撤销

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
