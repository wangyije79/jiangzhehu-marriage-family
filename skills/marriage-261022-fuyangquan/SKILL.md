# 抚养权归属

> 两周岁以下、八周岁意愿与最有利原则

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「孩子抚养权一般判给谁？」「两周岁以下一定归母亲吗？」

**什么时候会用到它**：

- 孩子抚养权一般判给谁
- 两周岁以下一定归母亲吗
- 怎么变更抚养权

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
孩子抚养权一般判给谁？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于离婚及离婚后的子女抚养争议，包括不同年龄段子女抚养权的判定原则、不满两周岁子女的例外情形、已满八周岁子女真实意愿的处理、抚养关系的变更与协议变更，以及抢夺藏匿子女的救济途径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 子女不满两周岁 | 母亲是否存在患有久治不愈疾病、有抚养条件不尽义务等法定情形 | 不存在例外的，以由母亲直接抚养为原则；存在例外的，父亲请求直接抚养可获支持 |
| 子女已满两周岁未满八周岁，双方均要求直接抚养 | 哪一方的抚养条件更有利于未成年子女 | 按最有利于未成年子女的原则判决，符合优先考虑情形的可优先 |
| 子女已满八周岁 | 子女的真实意愿以及该方是否具备抚养能力 | 应当尊重其真实意愿，同时结合抚养能力与是否有利于成长综合判断 |
| 一方存在家暴、赌博吸毒、重婚或与他人同居、抢夺藏匿子女等情形 | 是否属于法定列举情形 | 按照最有利于未成年子女的原则，优先考虑由另一方直接抚养 |
| 离婚后要求变更抚养关系 | 是否落在四种法定情形之内 | 符合条件的应予支持；仅以自身条件改善为由的，通常不足以变更 |
| 发生抢夺、藏匿未成年子女 | 是否需要即时救济 | 可以申请人身安全保护令或者人格权侵害禁令 |

## 六、操作步骤

1. 先按子女年龄分段，确定适用原则还是例外
2. 把双方的抚养条件整理成可比对的材料清单
3. 针对主张方向收集证据：照护参与度、居住与就学稳定性、经济与照护能力
4. 存在家暴、赌博吸毒、抢夺藏匿等情形的，固定相应证据
5. 子女已满八周岁的，以适当方式了解并呈现其真实意愿
6. 能协商一致的，签订书面协议并明确探望与抚养费安排
7. 发生抢夺藏匿的，立即申请人身安全保护令或人格权侵害禁令

## 七、常见误区

- 以为两周岁以下一定判给母亲，忽略法定例外
- 以为收入高就能拿到抚养权，忽略成长环境的稳定性
- 把孩子的意愿当成唯一依据，忽略该方是否具备抚养能力
- 用抢夺、藏匿孩子的方式制造既成事实
- 想变更抚养关系却直接申请再审或请求改判原判决
- 协议变更时未约定探望与抚养费，留下新的纠纷

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
