# 检查表

## 事实与材料自查

- [ ] 子女年龄对应的适用规则是否已确认
- [ ] 抚养条件的材料是否已量化整理
- [ ] 是否梳理过对方是否存在法定不利情形
- [ ] 长期协助照护的祖父母或外祖父母情况是否已说明
- [ ] 已满八周岁子女的意愿是否已适当呈现
- [ ] 协议是否写明探望方式、时间与抚养费安排
- [ ] 是否评估过抢夺藏匿的风险并准备即时救济
- [ ] 主张变更的是否落在四种法定情形之内

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
