# 检查表

## 事实与材料自查

- [ ] 是否已确认对方行为落在五种法定情形之内
- [ ] 是否区分清楚主张的是重婚还是与他人同居
- [ ] 证据是否指向该项的构成要件
- [ ] 物质损失是否已按票据整理
- [ ] 是否在离婚诉讼中一并提出赔偿请求
- [ ] 作为被告时是否已明确表态并收到书面告知
- [ ] 自身是否存在法定过错情形
- [ ] 涉及家暴的是否已报警并申请人身安全保护令

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
