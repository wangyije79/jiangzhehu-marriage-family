# 离婚损害赔偿与过错

> 重婚同居、家暴虐待与赔偿范围

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「哪些情形离婚可以要赔偿？」「家暴怎么认定和举证？」

**什么时候会用到它**：

- 哪些情形离婚可以要赔偿
- 家暴怎么认定和举证
- 离婚损害赔偿能要多少

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
哪些情形离婚可以要赔偿？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于离婚损害赔偿的主张与抗辩，包括重婚、与他人同居、家庭暴力、虐待与遗弃、其他重大过错的认定，也覆盖赔偿请求的主体资格与提出时机、物质损害与精神损害的范围、双方均有过错时的处理，以及家庭暴力的即时救济与举证安排。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 主张离婚损害赔偿 | 对方行为是否落在重婚、与他人同居、家暴、虐待遗弃、其他重大过错五种情形内 | 在范围内的可主张；不在范围内的一般不予支持 |
| 区分重婚与与他人同居 | 是否以夫妻名义共同生活 | 以夫妻名义的按重婚，不以夫妻名义但持续稳定共同居住的按与他人同居 |
| 尚未离婚但想先索赔 | 是否已经起诉离婚 | 不判离不支持赔偿请求，不离婚单独提赔偿请求不予受理 |
| 作为被告被起诉离婚 | 是否同意离婚、是否主张赔偿 | 两个态度都要明确，赔偿请求按程序要求在诉讼中提出 |
| 双方都有法定过错 | 双方是否均符合五种情形 | 一方或双方提出的赔偿请求，人民法院不予支持 |
| 存在家庭暴力需要即时救济 | 是否存在正在进行的暴力或威胁 | 立即报警并要求出具告诫书，同时申请人身安全保护令 |

## 六、操作步骤

1. 对照五种法定情形定位，确定主张的具体项
2. 围绕该项的构成要件列出证据清单，区分夫妻名义与共同居住两条举证方向
3. 核算物质损害，按票据整理清单
4. 梳理精神损害赔偿的酌定因素，准备可比参照材料
5. 作为原告的，在离婚诉讼中同时提出赔偿请求
6. 作为被告的，明确是否同意离婚以及是否主张赔偿
7. 评估自身是否存在法定过错，避免因双方均有过错导致请求落空

## 七、常见误区

- 以为出轨就能要赔偿，忽略法定情形的限定
- 把重婚和与他人同居当成一回事，举证方向搞错
- 想先离婚再单独索赔，或者婚内不起诉离婚直接索赔
- 以为主张多少法院就判多少
- 自己也有过错仍坚持主张，导致请求被驳回
- 遭遇家暴不报警、不申请保护令，只事后找证据

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
