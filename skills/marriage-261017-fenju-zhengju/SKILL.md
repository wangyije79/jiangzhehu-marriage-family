# 分居与离婚证据

> 分居满二年、分居证据固定与过错证据

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「分居满两年就自动离婚吗？」「分居证据怎么固定？」

**什么时候会用到它**：

- 分居满两年就自动离婚吗
- 分居证据怎么固定
- 怎么收集对方过错证据

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
分居满两年就自动离婚吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于以分居为由起诉离婚的案件，包括分居满二年的判离事由、判决不准离婚后又分居满一年再次起诉的路径，也适用于分居事实与过错事实的证据固定、举证材料准备与取证合法性判断。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 主张分居满二年应当判离 | 是否因感情不和、实际分开居住、连续满二年 | 三项都成立且调解无效的，应当准予离婚 |
| 第一次起诉被判决不准离婚 | 判决之后双方是否又分居满一年 | 再次起诉的应当准予离婚，这条路径门槛更低 |
| 分开居住但原因不是感情不和 | 是否存在外派、进修、照顾老人等客观原因 | 不构成法定判离事由中的分居 |
| 需要证明分居事实 | 能否同时证明分开居住与分居原因 | 只证明分开居住的，判离事由难以成立 |
| 对方存在家暴或与他人同居的过错 | 证据能否体现持续性经常性，或者持续稳定地共同居住 | 固定证据并主张损害赔偿；遭遇家暴的先行申请人身安全保护令 |
| 当事人自身也有过错 | 是否符合应当准予离婚的法定情形 | 符合的不应因当事人有过错而判决不准离婚 |

## 六、操作步骤

1. 先定性：判断走“分居满二年”还是“判决后分居满一年”的路径
2. 确定分居起算日并固定当天及之后的时间凭证
3. 按居住、文字、第三方、生活痕迹四类材料收集证据
4. 证明分居原因：固定聊天记录中关于感情不和的表述
5. 涉及家暴或骚扰的，立即报警并申请人身安全保护令
6. 起诉时一并考虑财产保全，防止对方转移共同财产
7. 第一次未判离的，收到判决书后重新起算并留存原件

## 七、常见误区

- 以为分居满两年婚姻会自动解除
- 以为分房睡、同住一套房也算分居
- 只证明分开居住，不证明分居原因是感情不和
- 第一次没判离就放弃，错过判决后再分居满一年的路径
- 分居期间误以为各自收入已各归各的
- 用伪造材料或违法方式取证，导致材料被排除

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
