# 检查表

## 事实与材料自查

- [ ] 是否已确认分居原因是感情不和，而非外派、进修等客观原因
- [ ] 分居起算日是否明确且有凭证支撑
- [ ] 是否同时准备了“分开居住”和“分居原因”两类证据
- [ ] 居住证明与缴费凭证是否连续覆盖分居期间
- [ ] 聊天记录等电子证据是否保留了原始载体
- [ ] 第一次不准离婚的判决书原件是否保存
- [ ] 是否存在家暴情形，是否需要申请人身安全保护令
- [ ] 是否已评估财产转移风险并考虑申请保全

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
