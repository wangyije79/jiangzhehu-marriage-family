# 婚内房产归属

> 婚后购房、父母出资与加名减名的处理

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「婚后买房写一个人名字算共同财产吗？」「父母出资买房算赠与还是借款？」

**什么时候会用到它**：

- 婚后买房写一个人名字算共同财产吗
- 父母出资买房算赠与还是借款
- 房产证加名后离婚怎么分

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

在对话里问一句测试问题：


**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于婚内购房登记在一方名下的性质判断、父母为子女购房出资的赠与与借款之争、出资对象是一方还是双方的认定，以及一方擅自处分共同所有房屋时的善意取得判断、追房与索赔的路径选择、异议登记与财产保全的操作要点。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 婚后购房登记在一方名下 | 购房资金是否来源于婚后共同财产 | 用共同财产购房的，一般认定为夫妻共同财产 |
| 父母在婚前为双方购房出资 | 父母是否明确表示赠与双方 | 默认视为对自己子女个人的赠与 |
| 父母在婚后为双方购房出资 | 赠与合同是否明确约定只赠与自己子女一方 | 有约定从约定；无约定时按受赠财产规则并结合出资来源与比例处理 |
| 一方父母全额出资且无约定 | 是否存在明确的赠与合同约定 | 可判归出资人子女一方所有，并综合考量后确定是否补偿以及数额 |
| 一方擅自出售共同所有的房屋 | 买方是否善意、是否支付合理对价、是否已办理登记 | 三要件均满足的追回请求不予支持，可另行主张损害赔偿 |
| 发现对方正在处分共同房产 | 能否及时完成查询、异议登记与保全 | 应及时申请异议登记并起诉保全，防止过户完成后追回困难 |

## 六、操作步骤

1. 确认房屋的登记状态与购房时间，先划清婚前与婚后的界线
2. 梳理购房资金来源：首付、贷款、还贷、父母出资分别对应哪些账户
3. 判断父母出资的性质（赠与或借款）与对象（一方或双方）
4. 核查有无书面约定、赠与合同、借条、转账备注等关键文件
5. 如涉及擅自处分，第一时间查询不动产登记与抵押状态
6. 及时申请异议登记，并在期限内提起诉讼主张权利
7. 同步申请财产保全，按可能造成的损失范围确定担保数额

## 七、常见误区

- 以为房产证写谁的名字房子就是谁的
- 以为父母出资默认就是借款，忽略举证责任的要求
- 忽略父母出资性质与出资对象这两个层次的区分
- 以为签了合同就能追回房子，忽视过户完成后善意取得的效力
- 发现对方卖房后只交涉不及时保全，错过最佳时机
- 只盯着房屋本身，忽略可以另行主张损害赔偿

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
