# 检查表

## 事实与材料自查

- [ ] 房产登记在谁名下、何时登记，是否已经核实
- [ ] 首付款来源能否追溯到具体账户与具体日期
- [ ] 贷款合同与婚后逐月还款流水是否完整
- [ ] 父母出资是否有书面约定，是否写明了赠与对象
- [ ] 是否存在借条、转账备注、还款或催收记录
- [ ] 买方是否为近亲属或关联方，交易价格是否公允
- [ ] 是否已查询房屋当前的登记与抵押状态
- [ ] 是否已准备异议登记与财产保全的申请材料

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
