# 诉讼离婚与判离标准

> 感情破裂认定、第一次不判离与再次起诉

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「第一次起诉离婚为什么判不离？」「法院判决离婚的标准是什么？」

**什么时候会用到它**：

- 第一次起诉离婚为什么判不离
- 法院判决离婚的标准是什么
- 判不离后多久能再起诉

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
第一次起诉离婚为什么判不离？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于诉讼离婚中感情确已破裂的判断、五类应当准予离婚情形的对应与举证、军婚与男方诉权限制的识别，判决不准离婚后再次起诉的时间把握与分居证据固定，以及离婚损害赔偿请求与过错认定之间的关系处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 起诉请求判决离婚 | 事实能否对应民法典第一千零七十九条第三款的五类情形 | 符合且调解无效的，应当准予离婚 |
| 事实不在五类情形之内 | 能否证明感情确已破裂 | 能证明的判离；不能证明的先调解，通常判决不准离婚 |
| 一方被宣告失踪 | 是否有宣告失踪的生效裁判 | 另一方提起离婚诉讼的，应当准予离婚 |
| 首次判决不准离婚后 | 双方是否又分居满一年 | 满一年后再次起诉的，应当准予离婚 |
| 配偶为现役军人 | 是否征得军人同意、军人是否存在重大过错 | 除军人一方有重大过错外，应当征得军人同意 |
| 女方处于孕期、产后一年内或者终止妊娠后六个月内 | 提起离婚的一方是男方还是女方 | 男方不得提出；女方提出或者法院认为确有必要的除外 |

## 六、操作步骤

1. 把已知事实逐条对应到民法典第一千零七十九条第三款的五类情形
2. 确认是否存在宣告失踪、首次判不离后再分居满一年等特别情形
3. 核查是否属于军婚或者男方诉权受限的时间窗口
4. 按情形分类整理证据，每类情形配齐一组证据材料
5. 起诉时一并写明离婚、子女抚养、财产分割与损害赔偿的请求与依据
6. 预判第一次可能不判离，从判决之后第一天开始固定分居证据
7. 满足分居满一年条件的，及时提起第二次诉讼并同步主张财产与子女事项

## 七、常见误区

- 以为第一次起诉就能判离，忽略感情破裂的举证要求
- 把偶发关系当成与他人同居，未达法定认定标准
- 只有本人陈述，缺少报警、就医等客观证据
- 把过错与能不能离婚混为一谈，忽略自己有过错不影响判离
- 判决不准离婚后中断分居或者又共同居住，导致时间重新计算
- 忘记在离婚诉讼中一并主张损害赔偿，事后另行主张受阻

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
