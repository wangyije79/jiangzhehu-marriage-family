# 检查表

## 事实与材料自查

- [ ] 是否已确认事实对应哪一类法定情形，对应不上的如何举证
- [ ] 分居证据是否完整，能否体现连续性与实际居住地址
- [ ] 家暴证据是否包含报警记录、验伤就医材料与照片
- [ ] 主张同居的，是否具备持续、稳定共同居住的证据
- [ ] 是否核实过是否存在军婚或者男方诉权受限的情形
- [ ] 损害赔偿请求是否已经在离婚诉讼中一并提出
- [ ] 判决不准离婚的，是否已从判决之后开始固定分居证据
- [ ] 是否已计算分居满一年的时间节点与再次起诉的时机

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
