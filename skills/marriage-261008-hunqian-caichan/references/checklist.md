# 检查表

## 事实与材料自查

- [ ] 婚前财产是否已列明清单并保存取得凭证
- [ ] 婚后还贷是否有固定账户与完整流水
- [ ] 个人财产是否与共同财产账户混同
- [ ] 是否存在夫妻财产约定，形式是否为书面、财产范围是否具体
- [ ] 约定涉及房产的，是否已办理变更登记
- [ ] 协议中是否夹带了人身限制条款
- [ ] 加名登记是否写明份额
- [ ] 对方是否存在转移、隐匿共同财产的情形

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
