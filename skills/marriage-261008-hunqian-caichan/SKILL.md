# 婚前财产与婚前协议

> 婚前财产界定、协议效力与房产加名

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「婚前买的房子婚后算共同财产吗？」「婚前协议约定净身出户有效吗？」

**什么时候会用到它**：

- 婚前买的房子婚后算共同财产吗
- 婚前协议约定净身出户有效吗
- 房产证加名就等于分到一半吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
婚前买的房子婚后算共同财产吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于婚前财产的界定与保护、婚前协议与夫妻财产约定的起草审查、婚前或婚内房产加名的风险评估，也适用于离婚时主张个人财产、要求共同还贷补偿或抗辩对方分割请求的情形。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 婚前全款买房，登记在自己名下 | 是否有婚后共同还贷、是否产生经营收益 | 属于个人财产，不因婚姻关系延续而转化；婚后共同还贷部分及对应增值需向对方补偿，经营性收益一般认定为共同财产 |
| 婚前首付、婚后共同还贷 | 房产登记在谁名下、还贷资金是否来自共同财产 | 房子归登记一方，尚未归还的贷款为登记一方个人债务；共同还贷支付的款项及对应财产增值部分，由登记一方对另一方补偿 |
| 一方个人财产在婚后产生收益 | 该收益属于孳息、自然增值，还是经营性收益 | 孳息与自然增值仍属个人财产；经营性收益（如出租经营、投资所得）认定为夫妻共同财产 |
| 婚前或婚内约定房产赠与、共有 | 是否已办理变更登记、给予目的是什么 | 未办理变更登记的，赠与方可能撤销；已登记的，离婚时法院结合婚姻存续时间、孕育情况、过错、贡献及市场价格确定归属与补偿 |
| 签了婚前协议 | 约定的是财产还是人身权利 | 财产条款书面约定有效；限制再婚、放弃抚养权探视权等人身条款通常无效 |
| 房产证加名 | 登记是否写明份额、婚姻存续时间长短 | 写明份额的按份额；未写份额的原则上均等但可调整；婚姻存续时间较短且给予方无重大过错的，可能判归给予方 |

## 六、操作步骤

1. 把婚前财产逐项列清单：不动产、存款、股权、车辆、理财，写明取得时间与资金来源
2. 凭证归档：购房合同、付款凭证、贷款合同、还贷流水按时间顺序整理并电子化备份
3. 婚后还贷固定账户、固定日期转账，避免现金，形成完整资金轨迹
4. 区分财产属性：区分自然增值、孳息与经营收益，避免混同
5. 需要时签书面夫妻财产约定，写明财产范围、归属、生效条件与违约责任
6. 涉及不动产赠与或加名的，及时办理变更登记，不要只停留在协议层面
7. 加名时按实际出资写明份额，避免日后对分割比例产生争议

## 七、常见误区

- 以为结婚时间长了，婚前个人财产会自动变成共同财产
- 把婚前房产的租金、投资收益也当成个人财产
- 协议只写“净身出户”，不写财产范围和归属
- 约定房产赠与却没办变更登记，对方事后撤销
- 加名只写共同共有、不写份额，分割时说不清出资
- 用现金还贷，事后无法证明资金来源

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
