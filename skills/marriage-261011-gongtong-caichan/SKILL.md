# 夫妻共同财产认定

> 工资奖金、投资收益与个人财产的界限

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「婚后工资算共同财产吗？」「婚前股权婚后增值算谁的？」

**什么时候会用到它**：

- 婚后工资算共同财产吗
- 婚前股权婚后增值算谁的
- 个人财产会变成共同财产吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
婚后工资算共同财产吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于婚后工资、奖金、提成、公积金、住房补贴、基本养老金等收入的性质判断，婚前股权与个人财产婚后增值的归属认定，个人财产因加名、书面约定或者账户混同而发生性质变化的情形，以及离婚时共同财产范围与分割原则的初步判断。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 婚后取得的工资、奖金与劳务报酬 | 是否发生在婚姻关系存续期间 | 婚内取得即属共同财产，与发到谁的账户、谁在管钱无关 |
| 一方婚前财产在婚后增值 | 增值来源于市场行情还是婚后投入经营 | 自然增值与孳息仍属个人财产；婚后投入经营带来的增值属共同财产 |
| 婚后实际取得的分红与投资收益 | 是否属于以个人财产投资取得的收益 | 一般认定为夫妻共同财产 |
| 个人财产是否因结婚年限转化为共同财产 | 是否存在加名、书面约定或者严重混同 | 不因婚姻延续而自动转化；因行为转化的部分按该行为的性质认定 |
| 婚内取得的住房补贴、公积金、基本养老金 | 是否已经实际取得或者应当取得 | 属于“其他应当归共同所有的财产”，离婚时可以主张分割 |
| 怀疑对方隐匿收入 | 能否从流水、个税记录、社保基数中发现线索 | 可通过调查取证与保全手段固定财产线索后再主张分割 |

## 六、操作步骤

1. 先划时间轴：把结婚登记日与离婚生效日写下来，作为判断婚内外的基准
2. 按收入类型分类：工资奖金、投资经营收益、知识产权收益、公积金与各类补贴
3. 逐项标注性质：属于共同财产、个人财产，还是需要进一步判断的增值部分
4. 固定基准证据：整理婚前财产的来源凭证与婚前股权的价值基准材料
5. 调查隐蔽收入：调取银行流水、个税记录、社保缴纳基数，交叉比对
6. 区分行为与时间：确认是否存在加名、书面财产约定、账户长期混同等行为
7. 按照顾子女、女方和无过错方权益的原则，评估分割比例与主张路径

## 七、常见误区

- 以为婚后各管各的钱，收入就各自所有
- 以为分居期间的工资不属于共同财产
- 把个人财产在婚后产生的全部增值都当成共同财产
- 认为结婚满一定年限个人财产就自动转化为共同财产
- 个人账户与共同账户长期混用，导致财产性质无法举证
- 忽略公积金、住房补贴、基本养老金同样可以主张分割

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
