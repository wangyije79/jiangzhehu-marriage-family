# 检查表

## 事实与材料自查

- [ ] 是否已明确婚姻关系存续期间的起止时间
- [ ] 工资、奖金、提成、年终奖的发放凭证是否齐全
- [ ] 公积金、住房补贴、基本养老金的账户明细是否已调取
- [ ] 婚前财产的来源证据是否完整、能否追溯到具体账户与日期
- [ ] 婚前股权是否已固定结婚登记日的价值基准
- [ ] 婚后参与对方经营的相关证据是否保留
- [ ] 个人账户与共同账户是否存在长期混同
- [ ] 是否存在加名、婚内财产协议等改变财产性质的行为

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
