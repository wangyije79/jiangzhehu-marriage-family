# 检查表

## 事实与材料自查

- [ ] 是否已确认属于三种无效情形之一，或符合撤销事由
- [ ] 起诉时无效情形是否仍然存在
- [ ] 是否已核算一年期限的起算日与届满日
- [ ] 胁迫证据是否已固定（内容需体现具体要挟）
- [ ] 疾病诊断、病历、用药记录是否已调取
- [ ] 本人知情时点是否有证据支撑
- [ ] 诉讼主体资格是否符合解释（一）第九条的限定
- [ ] 是否已同步主张财产处理与损害赔偿

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
