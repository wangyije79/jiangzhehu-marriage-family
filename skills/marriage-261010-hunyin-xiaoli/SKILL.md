# 婚姻效力与撤销

> 无效婚姻、可撤销婚姻与隐瞒重大疾病

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「哪些婚姻是无效的？」「被胁迫结婚怎么撤销？」

**什么时候会用到它**：

- 哪些婚姻是无效的
- 被胁迫结婚怎么撤销
- 对方隐瞒重大疾病能撤销婚姻吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
哪些婚姻是无效的？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非婚姻家事问题**：结婚、家庭关系、离婚、财产与债务、抚养探望、继承以外的领域（如劳动争议、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于婚姻无效的认定与主张、胁迫婚姻与隐瞒重大疾病的撤销、撤销权期限的计算，也适用于无效或被撤销婚姻的财产处理、损害赔偿主张与主体资格的判断。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 主张婚姻无效 | 是否属于重婚、禁止结婚的亲属关系、未到法定婚龄三种情形 | 只有这三种情形可认定无效，其他理由法院裁定驳回 |
| 起诉时无效情形已消失 | 例如双方均已达到法定婚龄 | 人民法院不予支持确认婚姻无效 |
| 因胁迫结婚 | 是否存在以损害生命、身体、健康、名誉、财产相要挟 | 构成胁迫的可在胁迫终止之日起一年内请求撤销；该一年为不变期间，不适用中止、中断或延长 |
| 一方婚前患有重大疾病未告知 | 疾病是否达到重大程度、何时知情 | 可在知道或应当知道撤销事由之日起一年内请求撤销 |
| 婚姻被确认无效或被撤销 | 同居期间财产如何处理、谁是过错方 | 财产先由当事人协议，协议不成由法院按照顾无过错方原则判决；无过错方有权请求损害赔偿 |
| 不清楚该走撤销还是离婚 | 婚姻本身是否有效、是否在撤销权期限内 | 在期限内且符合撤销事由的走撤销；超过期限或不符合事由的按离婚处理 |

## 六、操作步骤

1. 先定性：判断属于无效、可撤销还是应走离婚，三条路径后果完全不同
2. 对照法定情形逐一比对，确认是否落在封闭列举范围内
3. 核算期限：胁迫自胁迫终止之日起一年，隐瞒疾病自知道或应当知道之日起一年
4. 固定证据：胁迫证据（聊天、录音、证人）；疾病证据（诊断、病历、用药记录）
5. 固定知情时点证据：陪诊记录、聊天记录、证人陈述
6. 确认诉讼主体资格，按不同无效情形对应不同的适格主体
7. 起诉时一并主张同居期间财产处理与无过错方损害赔偿

## 七、常见误区

- 用感情不和、隐瞒收入等非法定理由请求确认婚姻无效
- 以为结婚时间久了就不能撤销，忽略起算点是知情之日
- 把一年的撤销权期限当成诉讼时效，指望可以中止中断
- 只证明对方患病，不证明自己何时知情
- 撤销与离婚两条路径混用，导致请求被驳回
- 忽略无过错方的损害赔偿请求权

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
